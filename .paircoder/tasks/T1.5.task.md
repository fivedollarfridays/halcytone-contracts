# storage.sql + storage.py loader

Define the raw SQL DDL that every downstream repo wraps — no ORM, no SQLAlchemy layer. Tables: `sessions`, `baselines`, `annotations`, `state_summaries`, plus a `meta` table seeded with `schema_version`. `storage.py` exposes `SCHEMA_VERSION: int` (matching the seeded row) and `read_ddl() -> str` so consumers can apply the DDL at setup. Idempotent via `CREATE TABLE IF NOT EXISTS`.
