# SessionSummary pydantic model (versioned)

Author the end-of-session summary contract. `SessionSummary` carries aggregate statistics halcytone-publish writes into `manifest.summary` after a session ends. First field is `summary_schema_version: int` (default 1, `ge=1`) so AgentGrounds can key logic off the version when the shape evolves. Numeric fields cover the statistics the fleet actually uses today; range-bounded fields (`[0, 1]`) stay bounded so downstream consumers can trust them without re-checking.
